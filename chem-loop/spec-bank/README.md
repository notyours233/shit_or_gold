# spec-bank

This folder stores additional project specifications and contracts that are not part of the canonical "memory-bank" docs.

Guidelines:
- Keep files small and focused (avoid monolith docs).
- Prefer one file per concern (data processing rules, metric key lists, experience export format, etc.).
- When a spec changes a major milestone behavior (DB schema / eval/practice dataflow / core task definition), also update `memory-bank/architecture.md`.
